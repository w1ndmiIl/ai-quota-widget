# AI_bar v1.4.0

本版本集中完成多 Agent 数据接入、长期统计可靠性、界面交互和 API 估值更新。

## 主要变化

- 新增 OpenCode、Gemini CLI 和 Cline 本地 Token 数据源，并与 Codex、Claude Code、Antigravity 统一按来源和模型筛选。
- 新增无需打开 Antigravity 窗口的 Gemini 5h/周额度读取；后台服务完成刷新后立即退出，且不纳入 Claude/GPT 等外部模型额度。
- 顶部新增 Codex / Antigravity 额度滑动切换；Token 模型筛选不再改变左侧额度，并优化玻璃圆环内部的字体与布局。Antigravity 没有重置卡，第三项保持留白。
- 引入本地持久累计账本：源会话被客户端清理后，已结算 Token 不再消失；账本只保存时间、模型和用量，不保存对话正文。
- 模型列表按累计用量排序，每个 Agent 显示三行并在超出时独立滚动。
- 重构设置页，语言和主题改为按钮选择，数据源改为紧凑开关，修复横向滚动和焦点交互。
- 修复重置卡数量误读、接口限流缓存和窄卡文本裁切问题。
- 更新官方标准文本 API 价格；历史用量锁定原价格，新用量使用新价格。DeepSeek 根据时间戳按峰谷时段结算，缺少时间戳时采用最高价。
- 拆分 Electron 主进程模块并优化后台 worker、模型菜单重建和高频渲染。

## 隐私说明

应用仅读取当前用户本机的 Agent 会话用量字段。发布包不包含开发者本机的 `.userdata`、登录凭据、对话正文或用量缓存。
